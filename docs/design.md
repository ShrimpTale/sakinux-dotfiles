# 设计取舍

> 为什么是这几条，以及对应的真实数值。回到 [主页](../README.md)

| 选择 | 具体做法 |
|---|---|
| 只看一条栏 | waybar 拆成 **左/中/右三块浮岛**，缝隙透出壁纸；不做第二行、不做 dock |
| 毛玻璃只给浮层 | 模糊只在 waybar / rofi / wlogout 三个 layer 上开：半径 8、3 趟、噪点 0.02；普通窗口 `opacity = 1.0` 不透明、也不吃模糊，只有 Nemo 这类浮窗单独设 0.75 |
| 一个调色板 | 26 个色槽（Catppuccin 格式），waybar / wlogout / ghostty / GTK / 图标 / 光标 / 输入法全从它派生 |
| 工作区不用数字 | 顶栏显示 **Ⅰ Ⅱ Ⅲ … Ⅹ**，当前工作区一个 `●`，其余 `○` |
| 边框很轻 | 2px 紫边框（mauve）+ 10px 圆角 + range 4 的柔和阴影；浮窗单独去边框去阴影 |
| 动画克制 | 窗口开合 87% popin、layers 淡入与背景变暗**同速**结束，不同时演两段 |

## 代价

- **没有第二块屏的状态**：`hl.monitor` 用 `output = ""` + `preferred/auto`，多屏要自己写
- **没有 dock**：要开新程序只能 `Super+R` 或键位
- **顶栏信息量刻意少**：温度/电池/磁盘/网络/音量/亮度就这些，想要 CPU/GPU/天气得自己加模块
- **毛玻璃依赖 Hyprland**：换个合成器（Niri/Sway）这层观感就没了
