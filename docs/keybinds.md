# 键位

> 全键盘流的核心。`SUPER` = Windows 键。

`SUPER` = Windows 键。

**窗口管理**

| 键 | 动作 |
|---|---|
| `Super+Q` / `Super+C` | 终端 / 关窗 |
| `Super+E` | 文件管理器 |
| `Super+V` / `Super+P` / `Super+J` | 浮动切换 / 伪平铺 / 切分屏方向 |
| `Super+方向键` | 移焦点 |
| `Super+1..0` / `Super+Shift+1..0` | 切工作区 / 把窗口丢过去 |
| `Super+S` / `Super+Shift+S` | 特殊工作区「暂存器」/ 丢进去 |
| `Super+滚轮` | 切工作区 |
| `Super+拖拽` / `Super+右键拖拽` | 移动 / 缩放窗口 |

**常用动作**

| 键 | 动作 |
|---|---|
| `Super+R` | 启动器 |
| `Super+Alt+X` | 区域截图（存 `~/Pictures/screenshots` + 直接进剪贴板） |
| `Super+Alt+V` | 剪贴板历史 |
| `Super+Delete` | **wlogout 关机菜单** |
| `Super+Alt+{F,S,C,W}` | Firefox / Steam / VSCode / 微信 |
| `Super+Alt+T` | Timeshift 备份 |
| `XF86*` | 音量 / 亮度 / 播放控制 |
